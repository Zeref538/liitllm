# English lexicon for the code-switch scorer. One word per line, # starts a comment.
#
# Unlike the Tagalog list, this one deliberately includes CONTENT words as well
# as function words. The signature form of Taglish is intra-sentential borrowing
# of English content words into Tagalog syntax — "nag-commute ako sa office,
# na-late pa rin sa meeting" — where the English contribution is *commute,
# office, late, meeting* and barely a function word in sight. A function-word-only
# English list scores that sentence as ~0% English and throws away exactly the
# documents this project exists to find.
#
# Coverage is high-frequency English only. It does not need to be a dictionary:
# the score is a document-level fraction over hundreds of tokens, so missing rare
# words shifts the number slightly and never flips a decision.
